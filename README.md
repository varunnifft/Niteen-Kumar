# NK Exam Portal - online examination page

Public page for candidates and administrators of **NK Exam Portal** (developed by Niteen Kumar, MBF).

- Exam link format: `https://varunnifft.github.io/Niteen-Kumar/?code=EXAMCODE`
- The page talks to the NK Exam Portal server (Google Apps Script). Opening it never goes through Google's account check, so it works on phones signed in to several Google accounts.

This branch (`exam-pages`) holds only the published page. The website source is on `main`.
